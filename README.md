# RS KICKBOX — Android Foundation v0.3 CI

Native Android / Jetpack Compose foundation for the approved RS KICKBOX app. This repository is configured with a GitHub Actions workflow that builds an installable Android debug APK (`app-debug.apk`) for testing.

The project preserves the 43 approved application routes, EN/NL localization structure, Elite Gold visual direction, dedicated student/trainer flows, and native screens already implemented for Login, Dashboard, RS Academy, AI Coach, Session Player, Trainer Book and Trainer Dashboard.
