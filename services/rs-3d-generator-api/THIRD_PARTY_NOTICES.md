# Third-party engine notices

The RS API service is original project code. It invokes separately installed upstream engines and does not vendor their source.

Pinned engines:
- CharacterGen — Apache-2.0 — zjp-shadow/CharacterGen
- TripoSR — MIT — VAST-AI-Research/TripoSR
- UniRig — MIT — VAST-AI-Research/UniRig

Always preserve each upstream repository's license and notices in its installation directory. Model weights may have terms distinct from the source-code license; verify those terms before commercial deployment.

Hunyuan3D is intentionally not part of this stack because the license reviewed for this project does not provide the territorial fit required for our Netherlands/EU deployment.
